ClawApp Privacy Policy

This local copy is bundled with ClawApp. You can publish the same file later at https://clawapp.work/privacy.

English

Summary

ClawApp is designed as a local-first macOS app. OpenClaw state, configuration, and logs are stored inside the app sandbox on the user’s Mac. ClawApp does not include analytics or telemetry in v1.

What is stored locally

  • OpenClaw configuration and runtime state inside the app container
  • User preferences such as language, appearance, quit behavior, and debug logging level
  • Onboarding transcripts in local debug logs
  • Optional runtime logs when the user enables Metadata Only or Full Content logging

What may be sent over the network

  • Provider authentication and model traffic to services the user configures, such as OpenAI or OpenRouter
  • Optional channel traffic if the user configures integrations such as Telegram
  • Local gateway traffic stays on 127.0.0.1 by default

User controls

  • Disconnect the current provider from Settings
  • Clear debug logs without resetting the entire app
  • Reset the app to remove sandboxed OpenClaw data and return to onboarding

简体中文

摘要

ClawApp 是一个以本地优先为设计原则的 macOS 应用。OpenClaw 的状态、配置和日志保存在用户 Mac 上的应用沙盒中。ClawApp v1 不包含分析或遥测功能。

本地存储的内容

  • 保存在应用容器内的 OpenClaw 配置和运行状态
  • 语言、外观、退出行为和调试日志级别等用户偏好
  • 保存在本地调试日志中的引导过程记录
  • 当用户启用“仅元数据”或“完整内容”日志时产生的运行时日志

可能通过网络发送的内容

  • 发送到用户自行配置的提供商服务的认证和模型请求，例如 OpenAI 或 OpenRouter
  • 如果用户配置了 Telegram 等集成，相应的可选频道流量
  • 本地网关默认只监听 127.0.0.1

用户控制选项

  • 可在设置中断开当前提供商
  • 可单独清除调试日志，而不重置整个应用
  • 可重置应用，删除沙盒中的 OpenClaw 数据并返回引导流程
